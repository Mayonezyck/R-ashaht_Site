# R'ashaht project page

The public project page for [R'ashaht](https://github.com/Mayonezyck/R-ashaht), a community
Discord bot for riichi mahjong tournaments, casual games, jobs, gil, a store, and collectible
minions. Served with GitHub Pages from `index.html` on the `main` branch.

The page is a single self-contained file: images are embedded, and the only external requests
are Google Fonts. Player names, scores, prices, and the example minion in the mock Discord
cards are illustrative.
